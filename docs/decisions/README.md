# Decision Records

Narrative documentation describes how Payline behaves now. A design choice that a reader would otherwise question, or that someone would otherwise undo without knowing what it cost, is recorded here instead.

Each record has four sections: the context that forced the choice, the choice itself, what it costs and what it buys, and its status. A record is never edited once accepted. When a decision is replaced, a new record is added and the old one is marked as superseded.
